## Critical

- file: cache.py:9  [high]
  found_by: codex, gemini
  severity_origin: codex:critical, gemini:critical
  description: Path traversal. Both write_value (line 9) and read_value
    (line 15) build the cache file path by interpolating the unsanitized
    `key` parameter: `path = cache_dir / f"{key}.json"`. Path's `/`
    operator does not sanitize — a key containing `../../etc/passwd`
    or an absolute path will resolve outside cache_dir, allowing
    arbitrary file read or overwrite. Sanitize the key (allowlist of
    safe characters) or use `cache_dir.joinpath(key + ".json").resolve()`
    and verify the result is still under cache_dir.resolve().
  quote: |
    path = cache_dir / f"{key}.json"

## Serious

  found_by: claude, codex
  severity_origin: claude:serious, codex:serious
  description: File handle leak in read_value. The function opens the
    file via `path.open("r")` (no context manager), then calls
    json.load and an isinstance check before f.close(). If either raises
    (malformed JSON or non-dict cache value), f.close() is skipped and
    the file handle leaks. Replace with `with path.open("r") as f:`.
  quote: |
    f = path.open("r")
    data = json.load(f)
    if not isinstance(data, dict):
        raise ValueError("cache value is not a dict")
    f.close()
